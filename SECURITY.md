# Security

## Supported versions

Only the latest release of `tmuxscope` gets security fixes.

## Reporting a vulnerability

Please report privately. Do not open a public issue.

- Go to the [Security tab](https://github.com/fayez-nazzal/tmuxscope/security) of `fayez-nazzal/tmuxscope`.
- Click `Report a vulnerability` to open a private advisory.
- Include the version, the exact command you ran and what it did.

You get a first reply within seven days.
